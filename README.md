> **English summary:** Single-file browser-based AI screen capture & quiz overlay assistant powered by Google Gemini API (BYOK). Includes an interactive quiz simulator, solved question history, and floating-window tips — runs directly on GitHub Pages with no backend required.

## Co umí

- **Snímání obrazovky přímo v prohlížeči:** Bez instalace jakýchkoli programů, funguje čistě na straně klienta.
- **Plovoucí zobrazení při práci v jiné záložce:** Návod a režim, jak mít asistenta stále na očích vedle kvízu.
- **Interaktivní kvízový simulátor:** Možnost rovnou si vyzkoušet vyhodnocování otázek bez ostrého kvízu.
- **Historie vyřešených otázek:** Přehled předchozích dotazů a odpovědí.
- **Vlastní Gemini API klíč (BYOK):** Klíč se ukládá pouze lokálně v prohlížeči uživatele, žádný API klíč není součástí repozitáře.

## Jak spustit lokálně

Projekt je kompletně v jednom souboru `index.html` (Tailwind CSS přes CDN + čistý JavaScript). Stačí repozitář stáhnout a otevřít `index.html` v moderním prohlížeči (Chrome / Edge), případně použít živý odkaz výše.

> **Související projekt:** Android verzi aplikace najdeš v repozitáři [hubkalukas/cerect-asstent-2](https://github.com/hubkalukas/cerect-asstent-2).
